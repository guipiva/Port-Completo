## Sobre o autor

Sou Guilherme Tobias Piva, estudante de Desenvolvimento de Software Multiplataforma (DSM) no 5º semestre pela FATEC. Tenho paixão por tecnologia, resolução de problemas e criação de soluções práticas que gerem impacto real. Ao longo dos anos, desenvolvi projetos acadêmicos e pessoais que me ajudaram a ganhar experiência em front-end, back-end, bancos de dados e boas práticas de desenvolvimento.

## Experiência e projetos

- Eco-Viva — Site informativo sobre natureza: desenvolvimento front-end com foco em acessibilidade e responsividade. Trabalho com HTML, CSS e JavaScript, além de prototipação em Figma.
- Carita — Plataforma de doações: desenvolvimento full-stack com integração de formulários, autenticação básica e banco de dados. Uso de ferramentas de versionamento e gerenciamento de tarefas em equipe.
- Biogen — Sistema de gestão de energia de biodigestores: projeto de maior escala envolvendo integração com banco de dados, telas responsivas e automação de processos.

## Habilidades

- Front-end: React, React Native, HTML, CSS, JavaScript
- Back-end: Node.js, APIs REST, integração com bancos relacionais e não-relacionais
- Banco de dados: SQL Server, SQLite, MongoDB
- Ferramentas: Git, GitHub, Figma, Trello

## Como executar este projeto

Instale as dependências e rode com o Expo (recomendado):

```bash
npm install
npm run start
```

Abra o projeto com o Expo em sua plataforma desejada (Android, iOS ou web).
